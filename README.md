# مشوار — وسيط لوجستي B2B (سوريا)

تشغيل: `npm install` ثم `npm start` (Node 22.5+). عند أول تشغيل تُطبع بيانات حساب المدير مرة واحدة.

- المنشأة: /merchant — الكابتن: /captain (PWA قابل للتثبيت على أندرويد) — الإدارة: /admin
- اختبارات: `npm test`
- للإنتاج: ضع الخادم خلف HTTPS (Nginx/Caddy) وعيّن NODE_ENV=production و ADMIN_PASSWORD (انظر .env.example). GPS في المتصفح يتطلب HTTPS.

## الأمان
bcrypt + JWT (قابل للإبطال) + قفل الحساب بعد 5 محاولات + Rate limiting + Helmet/CSP + استعلامات مُهيّأة + تحقق من كل المدخلات + عزل الأدوار + إخفاء بيانات الزبون عن الكابتن قبل القبول + موافقة الإدارة على كل حساب + سجل تدقيق.
